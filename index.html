Conceito Bootstrap & UX

O Bootstrap é um framework CSS front-end popular que acelera o desenvolvimento de interfaces responsivas utilizando classes utilitárias prontas (como sistemas de grid, botões, modais e formulários).

Nesta versão V5, construímos modais customizados e alertas inline do zero para eliminar completamente o uso de bloqueios nativos do navegador como alert() e confirm(), elevando drasticamente a experiência do usuário (UX).
